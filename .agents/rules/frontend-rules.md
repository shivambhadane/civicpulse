# Frontend & Design Rules — Civic Pulse

## Design System & Aesthetics
1. **Rich Aesthetics**: First impressions must be modern, sleek, and high-contrast. Use dark mode / curated palettes, smooth glassmorphism overlays, and dynamic micro-animations.
2. **Typography & Styling**: Use Inter/Outfit fonts via Google Fonts. Use Vanilla Tailwind CSS and shadcn/ui components.
3. **Map Experience**: The interactive map is the primary user interface. Ensure Mapbox pin overlays, cluster badges, and hotspot pulse rings are vibrant and responsive.
4. **Mobile First**: All screens (map, wizard, detail view) must be fully responsive for mobile viewports.
5. **No Ad-Hoc Utility Duplication**: Build clean, reusable UI components inside `components/`.
